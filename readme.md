## Penjelasan

BurgerKIR merupakan website sederhana untuk pemesanan burger.
Website ini dibuat menggunakan HTML, CSS, dan JavaScript, yang
dimana pada website ini memiliki warna dominan putih, pink dan hitam. 
Menampilakn 3 menu, sebagi pilihan menu yang dapat di pilih oleh pengguna,
dan pengguna dapat mengetahui total harga yang ia terima atau dapatkan.

### Fitur
- Menampilkan menu burger
- Memilih burger
- Menampilkan harga
- Menampilkan total pesanan
- Melakukan pemesanan
